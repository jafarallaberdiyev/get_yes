A playful "Do you love me?" web page. **Yes** leads to a happy ending. **No** walks through three increasingly desperate pleas, and on the last one the No button runs away from the cursor, so "Yes" is the only way out 😄

## How it works

| Page | What happens |
|---|---|
| `index.html` | The question, with Yes / No buttons |
| `no1.html` → `no3.html` | Each "No" leads to a more dramatic plea |
| `yes.html` | The celebration 🎉 |
| `script.js` | Moves the button to a random spot on hover |

Plain HTML, CSS and JavaScript, with no build step or dependencies (GIFs are embedded from Tenor).

## Run it

Open `index.html` in any browser, or serve the folder:

```bash
python -m http.server 8000
```
